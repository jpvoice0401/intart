# Sabrina · Teenage Witch

17번째 카메라 예제. 메뉴의 마법봉 아이콘 또는 `https://172.30.1.55:5174/?example=sabrina`로 엽니다. 기존 16개 예제와 기본 예제(rolex)는 유지합니다. 사용자가 `npm.cmd run dev`를 실행하며 에이전트는 개발/미리보기 서버를 실행하지 않습니다.

## 사용

1. 같은 Wi-Fi의 휴대폰이나 PC에서 HTTPS 주소를 열고 `카메라 켜고 마법 시작`을 누릅니다. 인증서·카메라 접근은 [HTTPS 안내](../HTTPS.md)를 따릅니다.
2. 얼굴·어깨가 잘 보이도록 카메라를 고정합니다. 머리부터 발끝까지 보이면 전신 의상과 신발이 함께 따라옵니다. 손바닥도 카메라에 보이게 합니다.
3. 왼손 또는 오른손의 엄지까지 펼친 손바닥을 잠깐 유지합니다. 다섯 손끝에 금빛·라벤더 빛이 모이고, 아래에서 위로 약 1.8초 동안 공주 의상이 나타납니다.
4. 다섯 가지 드레스와 다섯 가지 헤어 중 한 조합으로 변신합니다. 선택된 스타일 이름은 화면 오른쪽 위에 표시됩니다. 헤어밴드와 티아라, 소매/장갑, 신발도 몸을 따라옵니다. 얼굴은 본인의 원래 카메라 픽셀을 유지합니다. 배우의 얼굴로 바꾸거나 얼굴 형태/색을 보정하지 않습니다.
5. 변신한 뒤 어느 방향이든 한 바퀴 돌 때마다 드레스와 헤어가 함께 다음 조합으로 바뀝니다. 손을 다시 펼치면 손끝에 별빛이 켜집니다. `마법 풀기`는 변신을 해제하며 다시 변신하면 같은 조합을 유지합니다. `마법 체험` 버튼 또는 Space도 사용할 수 있습니다.
6. `Aa`는 화면 안내 표시를 전환합니다. 카메라 버튼은 트랙을 종료합니다. 마이크나 녹화·업로드 기능은 없습니다.

원래 카메라 배경을 유지합니다. 원래 옷이나 머리카락이 새 의상 밖으로 남는 부분은 실제로 관측한 배경을 먼저 사용하고, 아직 보이지 않은 부분은 주변 텍스처로 추정합니다. 카메라를 고정하고 잠시 빈 공간을 보여주면 그 배경을 기억해 더 자연스럽게 채울 수 있습니다. 가려져 있던 실제 물체를 정확하게 재구성하는 기능은 아닙니다.

## 표현 범위

MediaPipe의 화면 좌표와 3D 관절 좌표로 어깨·골반의 방향과 화면 속 의상 크기를 계산합니다. 치마, 소매, 신발, 헤어, 왕관은 몸 둘레를 감싸는 입체 메시이며 동일한 디자인이 앞·옆·뒤로 이어집니다. 웹캠 한 대로 깊이를 추정하므로 빠르게 돌거나 팔다리가 서로 가려질 때 정렬이 흔들릴 수 있습니다.

드레스는 별빛 볼가운, 달빛 A라인, 장미 꽃잎, 에메랄드 머메이드, 한밤의 벨벳의 다섯 가지입니다. 헤어는 모두 금발 계열이며 골든 블론드 웨이브, 샴페인 블론드 단발, 허니 블론드 땋은 머리, 베이지 블론드 포니테일, 라이트 블론드 올림머리의 다섯 가지입니다. 기존 이미지의 결·명암을 살리면서 본체와 뒤쪽 헤어 장식에 같은 금발 색조를 적용합니다. 페이지 세션에서 25가지 조합을 한 번씩 사용하고 다시 섞습니다. 주기가 바뀔 때도 직전 드레스와 헤어를 연달아 선택하지 않습니다.

회전은 몸의 방향 변화를 누적해 판정합니다. 좌우 흔들기와 반 바퀴 왕복은 조합을 바꾸지 않습니다. 추적이 오래 끊기거나 탭을 숨기면 진행 중인 회전 판정을 초기화합니다.

얼굴 윤곽은 FaceLandmarker의 얼굴 타원으로 보호하고 목과 실제 손도 원래 카메라에서 복원합니다. 머리 장식의 크기와 회전은 이마/턱/볼 위치에 맞춥니다. 의상을 모두 그린 뒤 같은 좌표의 원본 얼굴을 다시 합성하므로 얼굴을 의상 텍스처로 덮지 않습니다. 앞머리가 얼굴 윤곽 안으로 내려온 경우 일부 원래 머리카락이 남을 수 있습니다. 손 사이 틈, 가는 머리카락, 빠른 움직임과 분할 오차에도 잔상/경계 오차가 생길 수 있습니다.

정면은 얼굴 윤곽을 사용하고, 얼굴 인식이 끊긴 옆모습은 머리 방향에서 얼굴의 보이는 범위를 추정합니다. 뒤에서는 몸 추적으로 의상과 헤어를 계속 맞춥니다. 몸을 잠깐 놓치면 마지막 자세를 사용하고, 길게 놓치면 합성을 멈췄다가 자세가 돌아오면 같은 스타일을 다시 입힙니다. 상체만 보이면 치마를 화면 아래로 이어 그립니다. 신발은 전신이 화면에 들어왔을 때 발 관절을 추적해 그립니다.

## 파일과 성능

- `src/scenes/sabrina-scene.ts`, `src/sabrina.css`: 동의·카메라, 안내, 변신/초기화, 메뉴와 생명주기.
- `src/sabrina-model.ts`: 손바닥 판정, 380ms 유지, 추적 시점/유효성, 자세와 얼굴 기준점, 랜드마크 보간.
- `src/sabrina-models.ts`, `sabrina-vision.ts`, `sabrina-worker.ts`: 새 예제 전용 HandLandmarker(양손), PoseLandmarker Lite(한 사람), FaceLandmarker(한 얼굴). PoseLandmarker의 사람 마스크를 사용해 별도 ImageSegmenter 모델을 추가하지 않습니다.
- `src/sabrina-wardrobe.ts`, `src/sabrina-body3d.ts`, `src/sabrina-styles.ts`: 3D 관절에 맞춘 의상과 헤어 메시, 원본 소재의 표면 매핑, 25가지 조합 순환.
- `src/sabrina-turn.ts`: 양방향 한 바퀴 회전 판정, 흔들림과 추적 중단 처리.
- `src/sabrina-renderer.ts`: 투명 의상 렌더 타깃, 원래 배경/인물의 합성, 원본 얼굴/손 복원, 최대 210개의 손끝 빛·입자.

기존 `camera-access.ts`와 배경 기억/주변 텍스처 복원용 `MinecraftCapture`는 수정하지 않고 재사용합니다. 원래 배경이 관측된 영역을 우선 보존하며, 이 예제 세션의 별도 인스턴스만 만듭니다. 배경 복원 Worker도 동시에 한 작업만 수행합니다.

추론 입력은 Worker에서 긴 변 최대 640px이며 미지원 시 원래 크기를 전달합니다. 한 번에 한 모델/프레임만 분석하고, 손 75ms·자세 140ms·얼굴 220ms 이상의 독립 간격과 처리량에 따른 지연을 적용합니다. 메인 호환 경로는 GPU→CPU를 사용하고 각각 100/190/280ms 이상으로 조절합니다. 별도 얼굴 표정, 얼굴 변환 행렬과 GestureRecognizer는 로딩하지 않습니다. 카메라는 960×540/최대 30fps를 요청합니다.

렌더는 약 30fps, DPR 최대 1.5, 버퍼 최대 1440×1080입니다. 의상 메시/입자/사람 마스크/얼굴 보호 캔버스를 재사용합니다. 배경 학습은 최대 5Hz, 텍스처 복원 재처리는 최소 1.2초 간격이며 배경 텍스처도 같은 크기에서는 재생성하지 않습니다. 탭 숨김에서는 카메라 트랙/추론/입자 렌더/배경 Worker를 쉬고, 종료에서는 모델/Worker/트랙/타이머/이벤트/관찰자/캔버스/텍스처/메시/렌더 타깃/WebGL 컨텍스트를 정리합니다.

## 생성 이미지와 모델 출처

내장 `image_gen` 도구와 imagegen 스킬로 얼굴/피부/사람이 없는 드레스와 투명 얼굴 구멍을 가진 헤어·티아라 이미지를 새로 생성했습니다. 전경과 얼굴 구멍의 실제 alpha가 존재함을 확인했습니다. 원본을 워크스페이스의 `.tools/sabrina/`에 보관하고 크기/알파를 유지한 WebP로 내보냈습니다.

- `public/sabrina/dress.webp`: 1024×1536, 약 374KB.
- `public/sabrina/hair.webp`: 1024×1536, 약 475KB.
- 원본 경로, 내장 생성 도구/최종 프롬프트 전문, 자세 모델 원본 URL·버전·해시: [provenance.json](../public/sabrina/provenance.json).

새로 추가한 PoseLandmarker Lite는 Google 공식 float16 버전 1의 5,777,746바이트 모델입니다. 이 예제를 사용해 카메라를 켤 때만 요청합니다. 손/얼굴 모델과 WASM은 기존 로컬 배포 파일을 사용합니다.

- [Google Pose Landmarker: 33개 관절과 사람 분할 마스크](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker?tab=Web)
- [Google Hand Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker?tab=Web)
- [Google Face Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker?tab=Web)
