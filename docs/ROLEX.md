# 로렉스 손목 시계

소개와 조작 안내를 한국어로 통일하고, 반복되는 영문 장식 문구와 단계 안내를 제거했습니다. 손목 추적 상태와 카메라 종료 버튼은 연결 후 표시합니다.

로고는 [로렉스 공식 서버의 SVG](https://static.rolex.com/clocks/2020/explorers_all_HTML_270x90/css/images/logo/white/logo_rolex.svg)를 사용합니다. 2026-11-26에 받은 원본을 `public/rolex/rolex-logo.svg`에 그대로 보관했습니다. 왕관과 워드마크는 글꼴이나 직접 그린 도형으로 대체하지 않습니다.

`src/rolex-logo.ts`는 같은 원본의 여섯 경로를 Canvas `Path2D`로 그립니다. 시계 다이얼에는 전체 로고를, 용두에는 왕관 경로를 균일한 비율로 축소합니다. 다이얼의 금색·초록색은 시계 재질에 맞추고 원본 윤곽은 유지합니다. 실제 시계 문자판의 영문 각인은 유지했습니다.

레이아웃은 소개와 하단 상태·버튼을 그리드로 배치합니다. 세로 모바일에서는 소개와 시계 미리보기를 위아래로 나누고, 가로 화면에서는 좌우로 배치합니다.

검증: `npm run build:pages`, `node --test tests/rolex*.test.mjs`. 개발·미리보기 서버는 실행하지 않습니다.
