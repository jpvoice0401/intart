# 동물의 숲 · 우주 행성

상단 숲 아이콘이나 `?example=animalforest`로 들어갑니다. 다른 예제와 분리된 Three.js 장면입니다. 기존 게임의 로고·스크린샷·모델을 복제하지 않고, 둥근 행성 위의 숲과 작은 마을이라는 참고 이미지의 구성을 코드로 구현했습니다.

- 초록색 구형 지형 전체에 나무·벚꽃·집·연못·산책길·꽃·모닥불을 배치했습니다. 드래그·터치·방향키로 회전하고, 회전을 멈추거나 내 동물을 찾을 수 있습니다.
- 쥐·소·호랑이·토끼·용·뱀·말·양·원숭이·닭·개·돼지의 12가지 동물을 별도 3D 형태로 만들었습니다. 동물이나 이웃 목록을 누르면 찾아가 인사합니다.
- 이름과 생년월일을 입력하면 **출생연도 기준 띠**로 입주합니다. 음력 설·입춘에 따른 경계 구분은 적용하지 않고, 화면에도 연도 기준임을 표시합니다. 월·일은 정원의 꽃 색에 반영합니다. 미래·잘못된 날짜는 거부합니다.
- 입주 동물은 우주에서 낙하산을 타고 내려옵니다. 착륙 전에는 활동을 시작할 수 없습니다.
- 낚시·복숭아 따기·꽃 심기·모닥불 춤은 동물이 장소로 이동해 5~7초 동안 수행합니다. 활동이 완료돼야 물건을 얻으며 중복 실행은 막습니다. 꽃 심기는 행성에 실제 꽃을 추가합니다.
- 반짝이는 별 1,100개, 궤도를 도는 작은 운석 3개가 있습니다. 화면이 활성화된 시간 기준 30초마다 무작위 별똥별, 60초마다 우주선이 지나갑니다. 숨겨진 탭에서는 애니메이션과 시계를 멈춥니다.
- 입주와 물건은 `animal-forest-resident-v1` 로컬 저장소에 저장합니다. 생년월일 원문은 저장·전송하지 않습니다. 실시간 다중 사용자나 서버 공유 마을은 아닙니다. 다시 입주하면 이 예제의 활동 기록만 새로 시작합니다.
- 예제를 나가면 rAF·이벤트·ResizeObserver·WebGL·재질·기하·텍스처를 정리합니다. 카메라·마이크는 사용하지 않습니다.
- 같은 동물·나무·집 안에서 같은 색의 부품을 합쳐 렌더링 호출을 줄입니다. 모바일의 행성은 제목과 조작 패널 사이에 전체가 들어오도록 크기를 계산합니다.

검증은 `node --test tests/animal-forest.test.mjs tests/experiment-switcher.test.mjs tests/optimization.test.mjs`와 `npm run build:pages`로 실행합니다. 개발·미리보기 서버는 실행하지 않습니다.
