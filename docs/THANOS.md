# 타노스

16번째 예제. 아이콘 메뉴의 손 모양 또는 `https://172.30.1.55:5174/?example=thanos`로 엽니다. 기존 15개 예제와 기본 예제(rolex)는 유지합니다. 에이전트는 개발/미리보기 서버를 실행하지 않습니다.

## 사용

타노스 화면은 메뉴·실험 번호·본문·시작 버튼·상태 문구·사용 안내의 왼쪽 기준선을 맞춥니다. 중복 브랜드와 제목을 정리해 본문 위에 `THANOS` 한 번만 표시합니다. 하단 안내와 조작 도구는 그리드 안에 배치하며, 좁은 화면에서는 세로로 쌓이고 낮은 가로 화면에서는 본문 옆에 시작 버튼을 둡니다.

1. 개발 PC의 프로젝트 터미널에서 사용자가 `npm.cmd run dev`를 실행합니다.
2. 같은 Wi-Fi의 PC·휴대폰에서 HTTPS 주소를 엽니다. 인증서·카메라 권한은 [HTTPS 안내](../HTTPS.md)를 따릅니다.
3. `카메라 켜고 시작하기`를 누르고 카메라를 허용합니다. 얼굴·상체와 손이 함께 보이게 합니다. 마이크는 요청하지 않습니다.
4. 왼손 또는 오른손의 엄지와 중지를 잠깐 맞대고, 중지가 손바닥 쪽으로 빠르게 내려오도록 손가락을 튕깁니다. 손바닥이 카메라에 보이고 손이 화면을 벗어나지 않는 방향이 좋습니다.
5. 손가락 스냅이 추정되면 인물이 약 4.2초 동안 조각나듯 사라지고, 인물 색을 가진 먼지가 흩날립니다. 약 6.1초 뒤에는 인물 없는 외계 행성 배경과 종료 문구가 남습니다.
6. `다시 나타나기`로 돌아옵니다. `스냅 체험` 버튼 또는 Space로도 동일한 효과를 체험할 수 있습니다. 빠른 동작이 잘 잡히지 않으면 `높은 감도`를 선택합니다.
7. `SOUND ON/OFF`는 합성한 스냅·저음·바람 효과음, `Aa`는 화면 안내 표시를 전환합니다. 카메라 버튼을 누르면 트랙을 종료합니다.

카메라를 켜기 전에는 권한을 자동 요청하지 않습니다. 스냅 때 카메라 영상·사람 윤곽의 같은 분석 프레임을 보관하고 그 프레임을 사라지게 하므로, 동작 중의 몸이 새로 나타나지 않습니다. 배경은 실제 방을 지우는 것이 아니라 생성한 Titan 분위기의 풍경으로 합성합니다. 기록·업로드·다운로드·마이크 녹음 기능은 없습니다.

## 스냅 판정

새 예제 전용 MediaPipe HandLandmarker와 SelfieSegmenter를 사용합니다. 기존 예제의 모델 옵션이나 공용 추론 구현을 수정하지 않습니다. 얼굴/표정 모델과 정적 GestureRecognizer는 로딩하지 않습니다.

양손 최대 2개를 손목 위치로 대응시키고 손바닥 크기로 거리를 정규화합니다. 엄지 끝(4)과 중지 끝(12)의 짧은 접촉을 관측한 후, 240ms 안에 접촉이 빠르게 풀리면서 중지가 자신의 MCP(9) 쪽으로 반동하는 순서를 검사합니다. 검지 Pinch, 손바닥 펴기, 엄지만 움직이기, 손 전체의 이동·회전, 너무 느린 놓기는 스냅으로 처리하지 않습니다. 120ms 이내의 짧은 가림은 연결하며 1.6초의 중복 방지 간격을 둡니다. 효과가 시작된 이후에는 초기화 전까지 추가 스냅을 허용하지 않습니다.

이는 **영상 속 움직임으로 추정하는 제스처**입니다. 실제 손가락 마찰음이나 접촉을 측정하지 않습니다. 30fps 카메라의 모션 블러, 손 옆면, 조명과 가림 때문에 빠른 실제 스냅을 놓치거나 비슷한 엄지·중지 동작을 스냅으로 판단할 수 있습니다. 수치 테스트 통과가 실제 기기의 인식률 검증을 뜻하지 않습니다.

공식 참고 자료:

- [MediaPipe Hand Landmarker: 양손·21개 랜드마크·VIDEO 추론](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker?tab=Web)
- [MediaPipe Image Segmenter: 사람/배경 분할](https://developers.google.com/edge/mediapipe/solutions/vision/image_segmenter?tab=Web)

## 구현과 성능

- `src/scenes/thanos-scene.ts`, `src/thanos.css`: 카메라 동의, 안내/감도/음소거/재시작, 예제 전환과 탭 숨김 정리.
- `src/thanos-model.ts`: 스냅 상태와 손 대응, 먼지 방출 시점, 사라짐/종료 시간.
- `src/thanos-models.ts`, `thanos-vision.ts`, `thanos-worker.ts`: 로컬 손/사람 모델과 독립 추론 세션. 한 번에 한 작업만 처리해 프레임 대기열이 생기지 않습니다.
- `src/thanos-renderer.ts`: 인물/배경 합성, 사라짐 경계의 금빛과 인물 색 먼지. 같은 영상·마스크를 고정해 몸이 다시 나타나지 않습니다.
- `src/thanos-audio.ts`: Web Audio로 생성한 짧은 효과음. 영화 원음은 아닙니다. 반복 재생은 바람 효과의 제한된 구간에만 사용하며 5.6초 안에 모두 중지합니다.

Worker 추론 입력은 긴 변 최대 640px입니다. 비트맵 크기 조정 옵션을 지원하지 않으면 원래 크기를 전달합니다. Worker CPU 우선, 메인 GPU→CPU 호환 경로를 제공합니다. 손은 최단 40ms 간격, 사람 분할은 최단 150ms 간격으로 별도 스케줄링하고 처리 시간에 맞춰 늦춥니다. 메인 호환 경로는 원래 영상 입력과 각각 최소 60/190ms를 사용합니다. 카메라는 공용 접근 함수로 960×540/최대 30fps를 요청합니다. 실제 분석 빈도는 기기·처리량에 따라 낮아질 수 있습니다.

먼지는 최대 4,800개 점을 한 번의 draw call로 그립니다. 위치·색·방출 시점은 스냅 때 한 번 계산하고, 이후 이동은 GPU에서 처리합니다. DPR 최대 1.5, 렌더 버퍼 최대 1600×1200, 영상과 효과는 약 30fps로 제한합니다. 배경은 1672×941 WebP 약 240KB이며 이 예제를 열 때만 로딩합니다. 스냅 후 추론과 카메라 트랙을 비활성화하고 효과가 끝나면 rAF를 중단합니다. 다시 나타나기에서 트랙·추론을 재개합니다. 탭 숨김에서는 트랙·추론·오디오를 쉬고, 종료에는 모델/Worker/트랙/이벤트/ResizeObserver/타이머/텍스처/메시/WebGL·오디오 컨텍스트를 정리합니다.
